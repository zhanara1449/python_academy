## Запуск
Откройте **index.html** в браузере. На главной странице можно выбрать язык и класс. Квадратные карточки классов ведут на learning.html, где сохранены уроки, практика, олимпиады, инклюзивные задания и сертификаты.

## Файлы
- index.html, home.css, home.js — новая главная страница;
- learning.html, style.css, app.js, data.js, lectures.js, translations.js, extras.js — образовательный раздел;
- school-emblem.jpg — эмблема, предоставленная пользователем.

Данные о прогрессе хранятся в localStorage браузера. Проверка решений не выполняет Python-код. Некоторые старые практические вопросы могут оставаться на русском при выборе других языков.

## Публикация
Загрузите содержимое папки на статический хостинг, например Netlify. Главный файл — index.html.
